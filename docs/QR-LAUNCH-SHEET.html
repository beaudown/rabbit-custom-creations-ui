First-run sequence

  1. Open r1 Creations, choose add via QR, and scan only the testing Creation install QR.
  2. Open the installed A1 Broker Test Creation card.
  3. Confirm the broker endpoint is the HTTPS relay URL.
  4. Enter the relay token manually if the app asks for it.
  5. Run Step 1 and Step 2 only.
  6. Stop before service, approval, ADB, fastboot, root, reboot, install, or cleanup controls.
