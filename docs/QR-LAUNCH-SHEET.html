First-run sequence

  1. Open the hosted PWA and confirm the page loads.
  2. Run the First Run / Readiness panel.
  3. Confirm service-worker/cache support if the Rabbit browser exposes it.
  4. Import or call the Creation manifest.
  5. Use broker detection only against safe dry-run endpoints.
  6. Stop before ADB, fastboot, root, boot-cycle, or device mode changes unless separately authorized live.
