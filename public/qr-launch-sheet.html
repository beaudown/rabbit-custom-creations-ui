Safe first run

  1. Open r1 Creations, choose add via QR, and scan only the first QR.
  2. Open the installed iMessage Hermes Broker Creation card.
  3. Confirm the Rabbit gateway endpoint is the HTTPS relay URL.
  4. Confirm the Rabbit-reachable Hermes endpoint is prefilled as https://michaels-macbook-pro.tailcfaeac.ts.net.
  5. Confirm the iMessage broker endpoint is prefilled on port 10000.
  6. Use only the displayed GET messages and POST reply contracts.
